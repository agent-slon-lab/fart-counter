## 🌟 Возможности

### 🎭 Два режима приложения

- 🔥 **Весёлый режим** — полный функционал: пуки, теги, звуки, геймификация, магазин, юмор
- 🩺 **Медицинский режим** — серьёзный трекер ЖКТ: еда, туалет, аналитика, отчёт для врача. Без шуток

Переключается в Профиле. В medical-режиме скрыты пук-секции, магазин, история — остаётся чистый клинический интерфейс.

### Основное (весёлый режим)
- 📊 **Счётчик пуков** с большой кнопкой +1 и анимацией
- 🏷️ **11 тегов**: Тихий, Вонючий, Громкий, Долгий, В туалете, Случайно, Шептун, Прострел, Музыкальный, Волна, Лягушачий
- 🔊 **14 звуков** + авто-выбор по тегу
- 🏆 **23 достижения** (20 + 3 легендарных)
- 📈 **Статистика** с графиками (Неделя/Месяц/Год) + экспорт CSV/JSON
- 📅 **Журнал** с календарём

### 🩺 Медицинский трекер ЖКТ (оба режима)

#### Данные туалета (по шкале Бристоля)
- 🚽 **Bristol Stool Scale** (тип 1-7, медицинский стандарт) с SVG-иконками
- 😣 **Тенезмы** — позывы без результата
- 🚫 **Чувство неполного опорожнения**
- 📊 **VAS шкала боли 0-10** (Visual Analog Scale)
- 🔊 **Борборигмы** (урчание) в списке симптомов
- 📝 **Симптомы**: вздутие, боль, тошнота, изжога, спазмы, урчание
- ✏️ **Редактирование** записей (время + Bristol + симптомы)

#### Дневник питания
- 🍔 **28 пресетов** (орехи, рыба, каша, кофе и др.) + свои продукты
- 📏 **Размер порции** (малая 🟢 / средняя 🟡 / большая 🔴)
- 🌾 **FODMAP-тегирование** по Monash University:
  - ✅ Низкое FODMAP (безопасно)
  - 🌾 Олигосахариды (фруктаны + GOS): пшеница, лук, чеснок, бобовые
  - 🥛 Лактоза: молочные продукты
  - 🍎 Фруктоза: яблоки, мёд, HFCS
  - 🍬 Полиолы: грибы, сахарные спирты
  - ⚠️ Другой триггер: жирное, кофеин, острое, алкоголь

### 📊 Клиническая аналитика (Insights, medical mode + PDF)

- 📊 **Hourly Heatmap** — карта походов в туалет по 24 часам, цветовая интенсивность, пик активности
- ⏱️ **Lag Windowing** — анализ времени реакции после еды в 3 окнах:
  - **0-2ч (желудок)** — рефлюкс/непереносимость жира
  - **2-6ч (тонкий кишечник)** — СИБР/быстрый транзит
  - **6-24ч (толстый кишечник)** — FODMAP-ферментация
- ⚠️ **Risk Ratio (RR)** — для каждого продукта с ≥3 употреблениями:
  - Формула: RR = P(симптом|после еды) ÷ P(симптом|без еды)
  - 95% доверительный интервал (Wald)
  - Бейджи: «Повышенный риск» (RR≥2), «Без выраженного», «Меньше симптомов» (RR<1)
- 🥗 **FODMAP-профиль** — распределение употреблённых продуктов по 6 категориям Monash с прогресс-барами
- 📅 Переключатель периода: **7 / 14 / 30 дней**

### 📄 Отчёт для гастроэнтеролога
- 🏥 **Медицинский отчёт** (PDF через печать браузера)
- Содержит: сводку, Bristol-распределение, топ-триггеры еды, график динамики, журнал симптомов
- + **Сводный дашборд** с heatmap, lag-анализом, Risk Ratio и FODMAP-профилем
- 📊 **CSV экспорт** сырых данных
- 📅 Выбор периода: **7 / 30 / 90 дней**

### Аналитика (весёлый режим)
- 🧠 **ИИ-инсайты** — до 9 автоматических паттернов (топ-день, пик времени, стрик, корреляции)
- 📅 **Недельный цикл** — показывает с первого дня
- 🕐 **Время суток** — 4 периода (Ночь/Утро/День/Вечер)
- 📊 **Тренд за месяц** с sparkline
- 🔮 **Пук-предсказатель** с confidence %

### Напоминания (шутливые, весёлый режим)
- 🌅 **Утренний туалет** (после 10:00) — 5 смешных вариантов
- 🚶 **Ходьба** (после 15:00) — 5 вариантов про перистальтику
- 🌙 **Вечерний** — не забудь внести пуки

### Прочее
- 💧 **Счётчик воды**
- 🚶 **Трекер ходьбы** (+8 XP за прогулку)
- 😊 **Дневник настроения** + корреляция с пуками
- 🌤️ **Погода и пуки** — смешные корреляции
- 🌍 **Мировой рейтинг** (анонимно)
- 💡 **100 фактов** на 7 языках (просвещение в обоих режимах)
- 📤 **Share-карточки** (Spotify Wrapped стиль)
- 👶 **Baby mode** — для малышей: мягкие цвета, газики вместо пуков
- 🛡️ **Анти-фарм профилей** — XP/ачивки только на основном профиле
- 🎮 **Уровни не откатываются** при покупке в магазине (maxXp)
- 🏆 **Сетка уровней** (12 уровней: 🌱 → 🚀)

| | |
|---|---|

| Стили | Tailwind CSS 4 + shadcn/ui |
