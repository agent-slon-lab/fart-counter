# 💨 Счётчик Пуков (Fart Counter)

> **Бесплатное офлайн PWA для отслеживания пуков.** Юмор, статистика, 23 достижения, дневник питания, погода, мировая карта. Без рекламы, без слежки.

**Версия: 1.7.7**

[▶️ Watch 30s demo](https://youtube.com/shorts/SU068NOUf_8)

🌐 **English version:** [README.en.md](./README.en.md)

Откройте приложение на телефоне и добавьте на главный экран:

- 🍎 **iPhone (Safari):** открыть ссылку → Поделиться → «На экран Домой»

## 🌟 Возможности

### Основное
- 📊 **Счётчик пуков** с большой кнопкой +1 и анимацией
- 🏷️ **11 тегов**: Тихий, Вонючий, Громкий, Долгий, В туалете, Случайно, Шептун, Прострел, Музыкальный, Волна, Лягушачий
- 🔊 **14 звуков** + авто-выбор по тегу
- 🏆 **23 достижения** (20 + 3 легендарных)
- 📈 **Статистика** с графиками (Неделя/Месяц/Год) + экспорт CSV/JSON
- 📅 **Журнал** с календарём

### Здоровье и питание
- 🍔 **Дневник питания** — 28 пресетов (орехи, рыба, каша, кофе и др.) + свои продукты
- 💨 **Корреляция еды и пуков** — узнай свои триггеры + смешные предупреждения
- 🚽 **Трекер туалета** с **шкалой Бристоля** (тип 1-7, медицинский стандарт) + симптомы
- 🚶 **Трекер ходьбы** — отмечай прогулки (+8 XP за прогулку)
- 💧 **Счётчик воды**

### 📄 Отчёт для гастроэнтеролога
- 🏥 **Медицинский отчёт** (PDF через печать) — сводка, Bristol распределение, топ-триггеры еды, график динамики, журнал симптомов
- 📊 **CSV экспорт** сырых данных для врачей-аналитиков
- 📅 Выбор периода: 7 / 30 / 90 дней

### Аналитика
- 🧠 **ИИ-инсайты** — до 9 автоматических паттернов (топ-день, пик времени, стрик, корреляции)
- 📅 **Недельный цикл** — показывает с первого дня
- 🕐 **Время суток** — 4 периода (Ночь/Утро/День/Вечер)
- 📊 **Тренд за месяц** с sparkline
- 🔮 **Пук-предсказатель** с confidence %

### Напоминания (шутливые)
- 🌅 **Утренний туалет** (после 10:00) — 5 смешных вариантов
- 🚶 **Ходьба** (после 15:00) — 5 вариантов про перистальтику
- 🌙 **Вечерний** — не забудь внести пуки

### Прочее
- 😊 **Дневник настроения** + корреляция с пуками
- 🌤️ **Погода и пуки** — смешные корреляции
- 🌍 **Мировой рейтинг** (анонимно)
- 💡 **100 фактов** на 7 языках
- 📤 **Share-карточки** (Spotify Wrapped стиль)
- 👶 **Baby mode** — для малышей: мягкие цвета, весёлые эмодзи-частицы (⭐💖🌈), газики вместо пуков
- 🛡️ **Анти-фарм профилей** — XP/ачивки только на основном профиле
- 🎮 **Уровни не откатываются** при покупке в магазине (maxXp)
- 🏆 **Сетка уровней** (12 уровней: 🌱 → 🚀)
- 🎨 **Темы** + 4 акцента
- 🌐 **7 языков**: 🇷🇺 🇬🇧 🇪🇸 🇵🇹 🇩🇪 🇫🇷 🇮🇳
- 📱 **PWA**: офлайн, установка на телефон, уведомления
- 🔄 **Автообновление** приложения

## 🛠 Технологии

| | |
|---|---|
| Framework | Next.js 16 (App Router) |
| Язык | TypeScript 5 |
| Стили | Tailwind CSS 4 + shadcn/ui |
| State | Zustand + localStorage |
| Графики | Recharts |
| Анимации | Framer Motion |
| Звуки | Web Audio API (синтез) |
| QR-код | собственная реализация (0 зависимостей) |

## 📁 Структура

```
src/
├── app/
│   ├── layout.tsx          # Корневой layout
│   ├── page.tsx            # Приложение (PWA)
│   └── landing/            # Лендинг для SEO
├── components/
│   ├── app/                # Экраны
│   ├── pwa/                # Install prompt, Update banner
│   └── ui/                 # shadcn/ui
├── lib/
│   ├── i18n.ts             # 7 языков
│   ├── store.ts            # Zustand store
│   ├── achievements.ts     # 23 достижения
│   ├── sounds.ts           # 14 звуков
│   ├── facts.ts            # 100 фактов
│   ├── version.ts          # Проверка обновлений
│   ├── notifications.ts    # Уведомления
│   ├── qr.ts               # QR-генератор
│   └── export.ts           # CSV/JSON экспорт
└── hooks/
public/
├── manifest.json           # PWA манифест
├── sw.js                   # Service Worker
├── version.json            # Текущая версия
└── icon-*.png              # Иконки
```
