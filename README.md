# 💨 Счётчик Пуков (Fart Counter)

Бесплатное офлайн PWA для отслеживания пуков. Юмор, статистика, 18+ достижений, дневник питания, погода, мировая карта. Без рекламы, без слежки.

## 🌟 Возможности

- 📊 **Счётчик пуков** с большой кнопкой +1 и анимацией
- 🏷️ **11 тегов**: Тихий, Вонючий, Громкий, Долгий, В туалете, Случайно, Шептун, Прострел, Музыкальный, Волна, Лягушачий
- 🔊 **14 звуков пука** (синтезированные через Web Audio API) + авто-выбор по тегу
- 🏆 **23 достижения** (20 обычных + 3 легендарных)
- 📈 **Статистика** с графиками (неделя/месяц/год)
- 📅 **Журнал** с календарём и редактированием
- 🍔 **Дневник питания** с корреляцией "еда → пуки"
- 😊 **Дневник настроения**
- 🌤️ **Погода и пуки** — смешные корреляции
- 🔮 **Пук-предсказатель** — прогноз на день
- 🌍 **Мировой рейтинг** (анонимно, без сервера)
- 💡 **100 фактов о пуках** на 7 языках
- 📤 **Share-карточки** (Spotify Wrapped стиль)
- 🎨 **4 темы + 4 акцента**
- 🌐 **7 языков**: RU, EN, ES, PT, DE, FR, HI
- 📱 **PWA**: офлайн, установка на телефон, push-уведомления

## 🚀 Быстрый старт (локально)

```bash
# Установка зависимостей
bun install
# или
npm install

# Запуск dev-сервера
bun run dev
# или
npm run dev
```

Откройте http://localhost:3000

## 🛠 Технологии

- **Next.js 16** (App Router)
- **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui**
- **Zustand** (state + localStorage persist)
- **Recharts** (графики)
- **Framer Motion** (анимации)
- **Web Audio API** (синтез звуков)
- **React Day Picker** (календарь)

## 📁 Структура

```
src/
├── app/                    # Next.js App Router
│   ├── layout.tsx          # Корневой layout + metadata
│   ├── page.tsx            # Главное приложение (PWA)
│   └── landing/            # Лендинг для SEO
├── components/
│   ├── app/                # Экраны приложения
│   ├── pwa/                # PWA-компоненты (install prompt)
│   └── ui/                 # shadcn/ui компоненты
├── lib/                    # Библиотеки
│   ├── i18n.ts             # 7 языков
│   ├── store.ts            # Zustand store
│   ├── achievements.ts     # 23 достижения
│   ├── sounds.ts           # 14 звуков (Web Audio)
│   ├── facts.ts            # 100 фактов
│   ├── notifications.ts    # Local notifications
│   ├── qr.ts               # QR-генератор (без зависимостей)
│   └── export.ts           # CSV/JSON экспорт
└── hooks/                  # React hooks
```
