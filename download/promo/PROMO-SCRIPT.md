### 🎮 Как собрать в CapCut (5 минут)

1. **Открой CapCut** → Новый проект (9:16)
2. **Добавь скриншоты** по порядку (01→02→03→04→05)
3. **Обрежь** каждый скриншот до нужной длительности (по сценарию)
4. **Добавь voiceover.mp3** как аудиодорожку
5. **Добавь текст** на каждый кадр (из колонки «Текст на экране»)
6. **Добавь музыку** из библиотеки CapCut (весёлая, тихая)
7. **Добавь переходы** между кадрами (Slide, Fade)
8. **Экспорт** → 1080p → готово!

### 📱 Альтернатива: собрать прямо в TikTok

1. Открой TikTok → Загрузить
2. Выбери 5 скриншотов
3. Длительность каждого: ~6 сек
4. Добавь voiceover.mp3 как звук
5. Добавь текст на каждый кадр
6. Опубликуй!
